This project implements the data layer and topic architecture for a home patient-monitoring system. Sensor and smart-home events are streamed through Kafka into two agent tiers — a fast, deterministic Tier 1 for time-critical alarms, and a slower, reasoning-based Tier 2 that combines context (patient state + environment) to catch cases a simple rule table would miss. The system's output is a severity-tagged network-support request, not a direct action — the architecture stops at "here's what should happen next."
